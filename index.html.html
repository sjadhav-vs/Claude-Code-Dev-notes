Claude Code, before and after

Same task, two ways of asking.

    Developer session

    On its own, it can

    • Read and search your whole repo
    • Run commands: tests, builds, git
    • Edit many files in one go
    • Use connected tools like Figma, Linear, or Datadog

    It can’t, unless you help

    • Know your team’s unwritten rules
    • Know why a change is needed or what “done” means
    • Guarantee its work is correct, so reviews and checks still matter
    • Be trusted with secrets or client data it doesn’t need

    Four habits that make the difference

    Pick the right model

    • Sonnet for everyday coding, debugging and tests
    • Opus for hard problems: design, tricky bugs, big plans
    • Haiku for quick, simple jobs like renames or small scripts
    • Switch any time with /model

    Keep context lean

    • /clear between unrelated tasks
    • /compact when a long session starts drifting
    • /context to see what’s filling the window
    • Point at files with @path and paste only the relevant log lines
